# 📖 [프리미어 클린] 관리자 홈페이지 수정 매뉴얼

안녕하세요! 이 매뉴얼은 **코딩을 전혀 몰라도 초등학생도 쉽게 따라 할 수 있는 홈페이지 수정 안내서**입니다.
홈페이지의 모든 글자, 전화번호, 사진, 카카오톡 주소, 인스타그램 사진 개수는 오직 **`src/config/site.ts` 파일 하나**에서만 수정하시면 즉시 웹사이트 전체에 자동 반영됩니다!

### 1. 전화번호 및 카카오톡 상담 링크 바꾸기
- **수정 위치**: `site.ts` 파일의 `contact:` 부분
```typescript
contact: {
  phone: '1800-0000',      // 👈 여기에 사장님 대표 전화번호를 적으세요 (화면 표시용)
  phoneTel: 'tel:1800-0000', // 👈 전화 걸기 링크 (앞에 tel: 을 꼭 유지해 주세요)
  operatingHours: '매일 08:00 ~ 21:00 (연중무휴)', // 👈 상담 시간
  kakaoChatUrl: 'https://open.kakao.com/o/사장님오픈카톡주소', // 👈 1:1 카카오톡 오픈채팅 주소
  instagramUrl: 'https://instagram.com/사장님계정', // 👈 인스타그램 주소
}
```

---

### 2. 사업자 정보 및 대표자명 바꾸기
- **수정 위치**: `site.ts` 파일의 `company:` 부분 (웹사이트 맨 밑 푸터에 표시됨)
```typescript
company: {
  corporateName: '(주)프리미어클린마스터', // 👈 상호명
  ceo: '김대표',                         // 👈 대표자 성함
  businessNumber: '123-85-67890',         // 👈 사업자등록번호
  telecomSalesNumber: '2026-서울강남-0123호', // 👈 통신판매업신고번호
  address: '서울특별시 강남구 테헤란로 152', // 👈 회사 주소
}
```

---

### 3. 인스타그램 사진 노출 개수 조절하기
- **수정 위치**: `site.ts` 파일의 `instagram:` 부분
```typescript
instagram: {
  // 💡 숫자만 1, 2, 3, 4, 6 중 원하는 숫자로 바꾸시면 화면에 바로 반영됩니다!
  // - 1: 대표 사진 1장만 화보처럼 크게 돋보입니다. (추천)
  // - 3: 가로 3열 격자로 정돈되어 나옵니다.
  // - 6: 6개 사진이 꽉 차게 나옵니다.
  instagramMaxPosts: 1, 
}
```

---

### 4. 구역별 정밀 청소 비포/애프터 사진 및 매뉴얼 바꾸기
- **수정 위치**: `site.ts` 파일의 `cleaningManualZones:` 부분
- 주방, 욕실, 창호, 수납장, 바닥 각각의 시공 전(`beforeImage`), 시공 후(`afterImage`) 사진 링크를 넣으시면 정밀 매뉴얼의 슬라이더 사진이 즉시 바뀝니다!
```typescript
{
  id: 'kitchen',
  zone: 'KITCHEN ZONE',
  title: '주방 딥클리닝 & 150℃ 고온 스팀',
  summary: '기름때와 탄화물을 완전 분해 세척하여 새 주방처럼 복원합니다.',
  beforeImage: '청소 전 사진 인터넷 주소(URL)', // 👈 시공 전 사진
  afterImage: '청소 후 사진 인터넷 주소(URL)',  // 👈 시공 후 사진
  disassemblyTargets: ['렌지후드 금속 필터망', '가스레인지 화구', '싱크대 하부 걸레받이'], // 👈 탈거 목록
}
```

### 5. 4대 핵심 약속 및 안심 보증 문구 바꾸기
- **수정 위치**: `site.ts` 파일의 `coreValues:` 및 `trustBadges:` 부분
- '100% 한국인 직영', '고객 만족도 99%', '친환경 장비', '100% 무료 A/S' 등의 제목이나 설명 글을 원하는 단어로 자유롭게 수정하세요.

---

### 6. 자주 묻는 질문(FAQ) 내용 바꾸기
- **수정 위치**: `site.ts` 파일의 `faqList:` 부분
- `question`에는 질문을, `answer`에는 답변을 자유롭게 적으시면 아코디언 메뉴에 자동으로 예쁘게 들어갑니다.

---

### 7. 관리자 비밀번호 바꾸기
- **수정 위치**: `site.ts` 파일의 `integrations.adminPassword`
```typescript
integrations: {
  adminPassword: '0000', // 👈 기본값 '0000'을 원하는 비밀번호로 변경하세요!
}
```
- **관리자 모드 접속 방법**:
  - 모바일: 우측 상단 햄버거 메뉴를 누르고 맨 아래 `[🔒 관리자 모드]` 클릭
  - PC: 웹사이트 맨 밑 푸터(Footer) 최하단 저작권 옆의 작은 `[관리자]` 링크 클릭
  - 위에서 설정한 비밀번호를 입력하면 고객 후기 작성 창이 열립니다. (일반 고객에게는 절대 노출되지 않습니다)
